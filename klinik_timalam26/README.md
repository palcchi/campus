# Klinik Tim Malam 26

Project ini menggunakan CodeIgniter 4 dan Bootstrap 5.

## Menjalankan di GitHub Codespaces

Dari root repository:

```bash
cd klinik_timalam26
composer install
php spark serve --host=0.0.0.0 --port=8080
```

Setelah server berjalan, buka tab **Ports** lalu buka port **8080**.

Bootstrap sudah dipasang melalui CDN di `app/Views/home.php`.
